# PCD 点云测量工具 2.0 测试计划

## 1. 测试原则与数据集

每项功能至少覆盖：正常路径、边界值、无效输入、退化数据、状态切换、工程恢复、导出回读和旧功能回归。数值算法使用可手算的合成点云断言；GUI 使用 QtTest 驱动真实控件；大数据性能使用实际彩色地图自动回归，关键布局同时保存截图做视觉复核。

固定数据集：

- `xyz_no_color_ascii.pcd`：12 个无颜色点，验证高度着色与小数据边界。
- `rgba_ascii.pcd`：12 个 RGBA 点，验证颜色转换。
- `invalid_points_ascii.pcd`：包含 NaN/Inf，验证清理与计数。
- 合成平面/斜面/圆/方体/离群点/平移点云：测试程序运行时构造，答案精确已知。
- `odin1_colored_map_20260902_111205.pcd`：1,514,634 点真实回归地图。
- 运行时生成的 ROS1 bag、ROS2 SQLite/压缩 SQLite/MCAP：包含规则时序、长间隙、倒退、QoS、TF 和传感器故障注入。
- `static_20260716_typed`：2,933 条真实 ROS2 Livox/IMU 消息，用对应工作空间验证自定义消息与字段级分析。

通过标准：自动测试 0 失败；数值误差在每个用例声明的容差内；真实地图点数与推荐尺寸不发生非预期变化；导出文件可重新读取；失败路径不崩溃且不破坏当前工程状态。
