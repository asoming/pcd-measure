# 点云测量工具 2.3 完整功能矩阵

本文件把此前参考 CloudCompare、Potree、MeshLab、RViz 与 GIS 测量软件得到的功能建议收敛为可验收范围。目标不是复制这些软件的全部模块，而是完成“打开点云后，查看、选区、测量、分析、对比并形成可恢复工程和报告”的完整闭环。

## A. 文件与工程

- PCD ASCII、binary、binary_compressed 加载。
- PLY 顶点点云、MAPV0001 设备地图 BIN 和 Odin OLX 多帧会话加载。
- MAP BIN 内容魔数/version 检查；按架构下载并校验官方转换器，不把第三方二进制提交到仓库。
- OLX 15 B XYZRGB 与 16 B XYZRGBA 自动判别；严格检查帧头、点数、偏移、时间戳、截断和非有限坐标。
- 索引 `OdinPose.bin`、`OdinImage.bin` 与外部图片，并对缺失配套数据安全降级。
- XYZ、RGB、RGBA、无颜色、非有限点和损坏文件处理。
- 点击、拖放、最近文件、最近工程和启动参数打开。
- 大点云显示降采样，全部统计和测量继续使用完整点云。
- 当前区域、清理结果、主平面、对齐后点云另存为压缩 PCD。
- v7 工程保存点云路径、相机、显示、OLX 时间轴、选区、测量、分析和点云对比状态；v1–v6 及 `.odinpcd` 可继续读取。
- 自动恢复文件，正常退出或主动保存后清理恢复状态。

## B. 三维查看

- 旋转、平移、缩放、适应窗口和标准视角。
- 透视/正交相机、点大小、背景、坐标轴、地面网格和稳健包围盒。
- RGB、高程、纯色和点云差异热力图。
- OLX 帧标签着色、单帧/累计、全部历史/滑动窗口、播放倍率和同步相机预览。
- 完整点云上下文、局部/分析派生区域、第二点云和测量文字标签的可见性控制。

## C. 选区与裁剪

- 鼠标两点 XY 裁剪。
- 数值化 XYZ 三维框裁剪。
- 三维框反选。
- 使用已保存面积边界进行多边形套索裁剪及反选。
- 高度范围筛选。
- 局部点数、比例、边界、中心、主方向尺寸、密度、间距和高度分布。
- 导出当前区域并无损恢复完整点云。

## D. 测量与标注

- 单点坐标、两点距离、连续折线、三点角度、多边形面积。
- 正交分解、点到平面、三点圆/直径。
- 最近真实点吸附；显示 A/B/节点、线、圆、投影和标签。
- 米/厘米/毫米同步切换。
- 名称、分组、备注、颜色、显示状态和坐标编辑。
- 表格筛选、按组显示/隐藏、复制记录、删除、清空和 100 步撤销/重做。
- CSV/JSON 导出与 JSON 测量记录导入。

## E. 局部分析

- 区域 PCA 平面拟合：法向、坡度、方位、RMS、最大残差。
- 点密度、最近邻间距和高程统计。
- 高程直方图。
- 沿已保存折线提取带宽剖面，按里程分箱，显示最小/平均/最大高程并导出 CSV。
- 按已保存面积边界和基准高程进行栅格体积估算，给出高于、低于、净体积、覆盖面积和空栅格比例。
- 统计离群点检测/移除，结果预览、导出和恢复。
- RANSAC 主平面提取，给出内点率、方程和残差，并可导出平面内点。

## F. 双点云对比

- 加载第二个 PCD。
- 原坐标直接比较或质心预对齐后 ICP 精配准。
- 设置体素大小、最大迭代、对应距离和差异阈值。
- 显示收敛状态、适配度、4×4 变换矩阵。
- 计算第二点云到基准点云的最近距离；显示均值、RMSE、中位数、P95、最大值和超阈值比例。
- 蓝—青—黄—红差异热力图、第二点云显隐和透明度。
- 导出对齐点云、逐点距离 CSV 和对比摘要 JSON。
- 清除对比后恢复原显示模式。

## G. 坐标与输出

- 设置显示原点偏移，不改变源数据。
- 对点云应用平移、绕 Z 旋转和统一尺度的可逆预览。
- 导出变换后的 PCD 和 4×4 变换矩阵 JSON。
- PNG 当前视图、CSV/JSON 数据、A4 PDF 报告。
- PDF 包含截图、整体统计、测量记录、选区分析、剖面/体积和点云对比摘要。

## H. 质量、性能与可用性

- 所有耗时分析显示忙碌状态，异常后恢复界面。
- 输入范围校验、空结果、退化几何、NaN/Inf、只读目录和文件丢失提示。
- 所有新状态写入工程时带版本号；旧 v1–v6 工程继续读取。
- 科技测量台视觉体系：深空蓝、仪器青、测量橙和等宽数据字体；危险操作使用克制的红色。
- 键盘快捷键、焦点样式、自然按钮文案和非阻塞状态反馈。

## I. ROS Bag 回放与离线诊断

- ROS1 `.bag`、ROS2 SQLite、文件压缩 SQLite、ROS2 MCAP、独立存储文件和多分片 bag 识别。
- 录制元数据、文件大小、时长、话题类型、消息总数与 metadata/实际索引一致性检查。
- 每话题平均/中位频率、中位/P95/P99 周期、稳健抖动、长间隙、估算缺失、重复时间戳和时间回退。
- `header.stamp` 有效率、回退、采样时间与存储时间延迟，以及 header/存储时基切换。
- QoS 元数据解析、混合 reliability/durability、`/tf_static` durability 风险和缺失元数据提示。
- TF 图连通分量、多父节点、环、静态外参变化、无效变换、四元数归一化、平移/旋转跳变、速度尖峰、更新断档、净漂移和累计路径。
- IMU、LaserScan、PointCloud2、Livox CustomMsg、Image、Odometry、JointState、NavSatFix、BatteryState 和 DiagnosticArray 字段级健康检查。
- 无效值、空帧、载荷长度不一致、量程饱和、重复/冻结帧、短期 IMU 变化、里程计跳变、GNSS 无定位、低电量、过温和硬件主动告警模式。
- 自定义消息工作空间 `setup.bash` 自动查找与手动选择；不可解码话题安全降级为存储层时序诊断并说明覆盖率。
- 深色信号完整性控制台：输入、阈值、进度、健康轨、问题证据、话题、TF、传感器、日志和报告分栏。
- JSON 与自包含 HTML 原子导出；每条问题提供严重度、置信度、影响和可执行修复建议。
- ROS1/ROS2 回放倍率、循环、`/clock`、暂停、继续和停止；路径作为独立参数传递，兼容空格和中文。
- 离线诊断保持 bag 只读，不启动 ROS 节点；报告明确区分确定异常、启发式风险与无法离线确认的 QoS/丢包结论。

## J. 设备采集与 OLX

- 点云测量、实时采集、Bag 诊断和环境安装采用同一主窗口四工作台布局，不创建独立功能弹窗。
- 检查 `2207:0019` USB 设备、ROS2 工作空间和点云话题状态。
- 可从界面启动/停止 Odin ROS2 驱动，也兼容用户已经启动的驱动。
- 从 `/odin1/cloud_slam` 或 `/odin1/cloud_raw` 录制点云，按选项同步位姿与压缩图像。
- SLAM `rgb/rgba` 原样保留；DTOF intensity 转灰度；统一写入 16 B XYZRGBA 点记录。
- 写出 `.olx`、`OdinPose.bin`、`OdinImage.bin`、兼容配套目录和实时状态 JSON。
- 录制过程显示帧数、写盘点数、地图点数、当前帧点数、位姿、图像、体素、错误和日志；累计画面可旋转、缩放，结束后可自动打开会话。
- SLAM 默认逐帧累计建图，空间体素合并重复区域并在接近 60,000 点时自动加粗；DTOF 默认显示当前帧，也允许手动切换。
- 实时画面使用原子临时文件更新，停止时强制发布最终地图；完整 OLX 始终逐帧全量写盘。
- 录制器不修改设备驱动 YAML；中断时关闭文件句柄并保留已完成帧。
- 真实 Odin1 已完成 30 帧、639,827 点、32 位姿的写入—读回闭环。

## K. 环境自检与安装

- 左下角固定环境入口；状态矩阵与安装日志内嵌在主窗口，只有 sudo 认证使用系统级模态输入框。
- 检查 Qt、PCL、VTK、CMake、Python 等固定 Ubuntu 软件包、程序构建、Bag 独立环境、MAP BIN 解码器、桌面入口和 ROS2 Humble。
- 首次源码安装由 `install_desktop.sh` 在程序尚不能启动时完成相同的系统依赖检测，再编译并创建桌面入口。
- 一键安装按系统包、程序构建、可选组件和桌面入口排序；已存在项目不重复安装，结束后重新检测实际结果。
- APT 仅接受脚本内固定的软件包白名单，不拼接界面输入；ROS2 与设备驱动配置只检测、不自动修改。
- 仅在 sudo 缓存不可用时显示密码遮蔽输入框；密码经标准输入发送，不进入参数、日志、设置或项目文件。
- 取消、空密码、缺少 sudo、认证失败、网络失败、脚本丢失和非零退出均显示明确状态，并允许修复后重试。
- 1100×700 最小窗口与 1540×920 推荐窗口下，六行状态矩阵、可选项、进度和日志保持可见。
