# PCD 点云测量工具

PCD 点云测量工具 1.2 是一个离线 Ubuntu 桌面点云查看与测量工具，支持 PCD 的彩色显示、尺寸统计和交互测量，并针对 Odin1 生成的彩色 PCD 做了优化。程序不需要启动 ROS。

## 从 GitHub 下载并安装

以下流程适用于 Ubuntu 22.04。程序只读取 PCD 时不需要 ROS，也不需要连接 Odin1。

### 1. 下载项目

安装 Git 并克隆仓库：

```bash
sudo apt update
sudo apt install -y git
git clone https://github.com/asoming/pcd-measure.git
cd pcd-measure
```

也可以在 GitHub 页面点击 **Code → Download ZIP**。解压后进入项目文件夹，在文件夹空白处右键选择“**在终端中打开**”。

### 2. 安装编译依赖

```bash
sudo apt update
sudo apt install -y \
  build-essential cmake \
  qtbase5-dev \
  libpcl-dev \
  libvtk9-dev libvtk9-qt-dev
```

### 3. 编译并创建桌面图标

在项目目录中执行：

```bash
chmod +x build.sh run.sh install_desktop.sh scripts/verify_features.sh
./install_desktop.sh
```

安装脚本会在首次运行时自动编译，并在桌面和应用程序菜单中创建“**PCD 点云测量工具**”。完成后即可双击桌面图标启动。

如果图标显示为普通文本文件，请右键该图标，选择“**允许启动**”，然后再次双击。不同 Ubuntu 桌面环境中的选项也可能叫“**信任并启动**”。

> 不要在安装后移动或删除项目文件夹，否则桌面图标会失效。如果移动了项目，进入新目录后重新运行 `./install_desktop.sh` 即可修复。

### 4. 终端启动（备用方式）

```bash
./run.sh
```

也可以启动时直接传入 PCD 文件：

```bash
./run.sh /path/to/your_cloud.pcd
```

## 打开文件与视图操作

- 点击“打开 PCD”，或把 `.pcd` 文件直接拖入窗口。
- 加载期间会显示文件名、动态进度条和 `LOADING` 状态；完成后切换为 `READY`。
- 点击“最近文件”可重新打开最近使用过的 8 个 PCD；已经不存在的文件会自动移除。
- 左键拖动旋转，鼠标中键拖动平移，滚轮缩放。
- 支持俯视、正视、左视、等轴视图和一键适应窗口。
- 保留 RGB/RGBA 颜色；没有颜色字段时自动切换为高度着色。
- 支持 RGB、高度渐变和单色显示，也可调整点大小和背景颜色。
- 支持透视相机与正交相机切换。
- 可显示坐标轴、稳健尺寸框和自适应间距网格。

## 两点测量

1. 在顶部模式栏选择“**两点测距**”。
2. 按住 **Shift** 并点击鼠标左键选择 A 点，再以同样方式选择 B 点。
3. 程序通过完整点云 KD-tree 吸附到最近的真实点，画出测量线并计算三维距离、水平距离、高度差、坡度和倾角。即使画面经过显示降采样，也不使用插值点测量。
4. 继续 Shift + 左键即可建立下一条测量；记录会自动编号。

## 多段折线测量

1. 在顶部模式栏选择“**连续折线**”。
2. 按住 **Shift** 依次点击路线节点，界面会实时显示当前累计长度。
3. 点击“完成折线”或按 **Ctrl+Enter** 保存这条折线。

记录表会显示类型、节点数、三维累计长度、水平累计长度和累计高度变化。“撤销”删除最近一条已保存测量，“全部清除”删除所有测量。

## 局部裁剪与统计

1. 在顶部模式栏选择“**局部裁剪**”，程序会切换到俯视图。
2. 按住 **Shift** 点击局部区域的两个对角，建立 XY 裁剪框。
3. 视图只显示框内点云，右侧“局部区域”卡片会显示局部点数、稳健长度、宽度、高度、三维对角线和中心坐标。
4. 点击“恢复完整点云”退出局部裁剪。

裁剪只影响显示和局部统计；整体尺寸、总点数等数据始终来自完整点云。

## 显示的数据

- 总点数、有效点、无效点、显示点数、彩色点数量与比例。
- 文件大小、字段和 PCD 编码。
- 点云质心、最低点 XYZ、最高点 XYZ、原始高度差、XYZ 坐标范围和中位最近邻点间距估计。
- 原始坐标轴包围盒的 X/Y/Z 尺寸和三维对角线。
- 推荐的稳健主方向长度、宽度、高度、水平对角线、三维对角线、主方向角和离群点处理比例。
- A/B 坐标、ΔX/ΔY/ΔZ、三维距离、水平距离、高度差、坡度和倾角。
- 多次两点或折线测量记录，以及累计三维长度。
- 局部裁剪区域的点数、稳健尺寸、对角线和中心坐标。

## 尺寸计算说明

界面同时显示两套尺寸。原始坐标轴包围盒保留全部有效点，容易被飞点拉大；推荐尺寸使用水平 PCA 主方向，并在投影后的每个方向剔除两端各 0.5%（每轴合计 1.0%），以降低离群点影响。界面中的橙色线框就是推荐的稳健主方向包围盒，并会显示 PCA 预清理的实际比例和保留点数。

Odin1/ROS 点云坐标默认按米解释。测量单位下拉框只改变显示单位，不改变原始坐标。点到点距离为：

```text
sqrt((Bx-Ax)^2 + (By-Ay)^2 + (Bz-Az)^2)
```

精度会受到原始点云分辨率、选点位置、传感器标定和 SLAM 累积漂移影响。本工具适合场景测量与快速核对，不替代经过标定的工程测量仪器。

## 导出、截图与工程文件

- “保存截图”导出当前三维视图为 PNG。
- “导出测量”可保存 CSV 或 JSON；折线会保存全部节点，JSON 还包含完整点云统计、整体尺寸和局部裁剪统计。
- “保存工程”生成 `.pcdmeasure` 工程文件，保存 PCD 路径、所有测量点、局部裁剪、显示设置和当前相机视角。
- “打开工程”可继续上次工作；也可以把 `.pcdmeasure` 拖入窗口，或将它作为 `run.sh` 的启动参数。旧版 `.odinpcd` 工程仍可打开。
- 工程同时记录 PCD 的绝对路径和相对路径，工程与 PCD 一起移动后仍会优先尝试相对位置。
- 超大点云会自动降低显示点数，但统计和尺寸始终使用完整有效点云。

常用快捷键：

- `Ctrl+O`：打开 PCD
- `Ctrl+Shift+O`：打开工程
- `Ctrl+Shift+S`：保存工程
- `Ctrl+Enter`：完成当前折线

## 单位与精度

单位可以在米、厘米、毫米之间切换。Odin1 点云坐标默认按米解释，切换单位会同步更新测量坐标、坐标差、距离和记录表，不会缩放或修改原始点云。CSV/JSON 字段名带 `_m`，始终按米导出，避免交换数据时产生单位歧义。

## 重新构建

完成前面的依赖安装后，修改代码可运行：

```bash
cd /path/to/pcd-measure
./build.sh
```

命令行分析器位于：

```bash
./build/bin/pcd_analyze your_cloud.pcd
```

它会输出 JSON，可用于批量检查或自动化验证。

## 自动验收

项目包含真实 GUI 与核心数据回归测试，覆盖 RGB/RGBA、无颜色点云、无效点、拖放、测距、折线、单位、裁剪、全量点吸附、颜色模式、背景、相机投影、视图、网格、尺寸框和工程恢复。完整验收需要使用开发时的基准地图运行：

```bash
cd /path/to/pcd-measure
./scripts/verify_features.sh /path/to/reference_cloud.pcd
```

脚本还会强制把当前地图降采样到最多 100,000 个显示点，并核对全量点数和推荐尺寸没有变化。
