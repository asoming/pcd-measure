# 点云测量工具

一款面向 Ubuntu 的中文桌面点云工作台。可以直接查看、测量、裁剪和分析 PCD、PLY、Odin MAP BIN 与 OLX，也可以连接 Odin1 实时查看并录制点云，以及回放并离线诊断 ROS1、ROS2 和 MCAP bag。点云、设备采集、Bag 诊断和环境安装使用同一主窗口内的四个工作台，不再打开独立功能窗口。

![点云测量工具主界面](docs/images/main-window.png)

> 截图由程序直接加载 1,514,634 点的彩色建筑点云生成。测试点云和用户数据不会放入仓库。

| 项目 | 说明 |
| --- | --- |
| 当前版本 | 2.3.0 |
| 已验证系统 | Ubuntu 22.04.5 LTS x86_64 |
| 核心依赖 | Qt 5、PCL、VTK、CMake |
| 点云输入 | PCD、PLY、MAPV0001 `.bin`、OdinViewer `.olx` |
| 设备采集 | ROS2 彩色点云累计建图预览并录制 OLX；已用真实 Odin1 验证 |
| ROS 数据 | ROS1 `.bag`；ROS2 SQLite、压缩 SQLite、MCAP |
| 数据安全 | 本地处理；源点云、OLX 和原始 bag 始终只读 |

## 关于

点云测量工具把常见点云任务集中到一个中文桌面界面中：打开一份点云或 OLX 会话后，可以立即检查数据质量和场景尺寸，完成点、线、角度、面积、平面和圆的测量，再继续做局部分析、双时相对比、坐标变换、工程保存和报告输出。

它适合以下场景：

- 机器人、SLAM、激光雷达和三维扫描数据的快速检查与现场采集。
- 在 Ubuntu 上连接 Odin1，从 ROS2 彩色点云、DTOF、位姿和可选相机话题录制 OLX。
- 房间、厂房、道路、墙面和设备点云的距离、面积与高差测量。
- 对局部平整度、高程分布、路线剖面和挖填体积做初步分析。
- 对两次扫描进行刚体配准，并定位变化区域。
- 在不启动 ROS 节点的情况下检查 bag 的时序、TF、QoS 和传感器异常。

查看和测量已有点云不依赖 ROS。只有连接设备录制 OLX 或执行 ROS bag 回放时，电脑才需要对应的 ROS 环境；离线 bag 诊断可在缺少 ROS 运行环境时完成基础索引分析，并在消息类型可用时执行字段级深度分析。

本工具强调现场核对、研发诊断和可复现报告，不替代经过检定的全站仪、测距仪或法定工程测量软件。

## 下载安装

### 1. 系统要求

当前发布流程已在 Ubuntu 22.04 x86_64 上完整验证。仓库提供源代码，目前没有预编译的 AppImage、`.deb` 或 Windows 安装包。

不需要预先逐项安装编译依赖，下面的 `install_desktop.sh` 会先自检，再只安装缺少的软件包。如果希望手动安装，固定的软件包清单是：

```bash
sudo apt update
sudo apt install -y \
  git curl build-essential cmake \
  python3-venv python3-pip python3-numpy \
  qtbase5-dev \
  libpcl-dev \
  libvtk9-dev libvtk9-qt-dev
```

ROS 不是点云查看和测量的必需依赖。需要回放 bag 时，再安装与 bag 对应的 ROS1/ROS2、storage 插件和自定义消息包。

### 2. 从 GitHub 下载

推荐使用 Git，这样后续可以直接更新：

```bash
git clone https://github.com/asoming/pcd-measure.git
cd pcd-measure
```

也可以在 GitHub 页面点击 **Code → Download ZIP**。解压后进入项目文件夹，在空白处右键选择“在终端中打开”。

### 3. 一键编译并创建桌面图标

```bash
chmod +x build.sh run.sh install_desktop.sh scripts/*.sh
./install_desktop.sh
```

安装脚本会：

1. 检查一份固定、可审计的 Ubuntu 软件包清单；有缺失时通过终端 `sudo` 安装，已存在的软件包不会重复安装。
2. 以 Release 模式编译程序。
3. 在项目内创建可选的 `.rosbag-venv`，安装 ROS1、压缩 bag 和 MCAP 的离线解析依赖。
4. 按 CPU 架构下载 Manifold 官方 MAP BIN 转换器并校验固定 SHA-256；下载失败不影响其他格式。
5. 在桌面和应用程序菜单中创建“点云测量工具”。

首次从源码安装时，Qt/PCL 尚未就绪就无法先打开图形界面，因此必须在项目目录执行一次 `./install_desktop.sh`。程序能够启动以后，后续检查和修复都可以直接使用左下角“环境安装”。

编译默认最多使用 2 个并行任务，避免 PCL/VTK 在内存较小的电脑上并行编译失败。需要手动增加时：

```bash
PCD_MEASURE_BUILD_JOBS=4 ./build.sh
```

如果暂时不需要 ROS bag 深度诊断，或安装时没有网络，可以跳过 Python 可选依赖：

```bash
PCD_MEASURE_SKIP_ROSBAG_SETUP=1 ./install_desktop.sh
```

以后需要时再执行：

```bash
./scripts/setup_rosbag_tools.sh
```

如果暂时不需要 MAP BIN，可跳过官方转换器下载：

```bash
PCD_MEASURE_SKIP_ODIN_MAP_SETUP=1 ./install_desktop.sh
```

以后需要时再执行 `./scripts/setup_odin_map_tools.sh`。转换器来自 Manifold 官方文档站，不存入本仓库；安装脚本会拒绝哈希不符的文件。

### 4. 第一次双击启动

安装完成后，双击桌面的“点云测量工具”。如果 Ubuntu 把图标显示为普通文本文件，请右键图标，选择“允许启动”或“信任并启动”，再双击一次。

桌面图标引用当前项目目录，因此安装后不要删除或移动项目文件夹。若移动了目录，请在新位置重新运行：

```bash
./install_desktop.sh
```

也可以从终端启动：

```bash
./run.sh
./run.sh /path/to/cloud.pcd
./run.sh /path/to/map.bin
./run.sh /path/to/recording.olx
./run.sh /path/to/project.pcdmeasure
```

### 5. 更新已有安装

Git 下载方式：

```bash
cd /path/to/pcd-measure
git pull
./build.sh
./install_desktop.sh
```

ZIP 下载方式需要重新下载并解压；如果目录位置改变，应重新执行 `./install_desktop.sh`。

## 五分钟入门指南

### 第一步：打开点云

点击左上角“打开点云”，或者把 `.pcd`、`.ply`、地图 `.bin` 或 `.olx` 文件直接拖入窗口。加载过程中会显示文件名、来源、解码方式、状态和进度；完成后状态变为 `READY`。

### 第二步：检查数据

先看右侧“文件信息”“点云统计”和“推荐主方向尺寸”：

- 确认有效点数是否符合预期。
- 确认 RGB/RGBA 是否存在，彩色点比例是否正常；地图 BIN 没有颜色是正常现象。
- 检查坐标范围、高低点和原始高度差是否有明显飞点。
- 使用推荐主方向尺寸了解场景主体的长、宽、高。

### 第三步：调整视图

- 左键拖动旋转。
- 中键拖动平移。
- 滚轮缩放。
- 使用俯视、正视、左视或等轴视图快速定位。
- 大点云操作卡顿时，降低“显示点上限”；统计和测量仍使用完整点云。

### 第四步：测量两个位置

1. 在视图上方选择“两点测距”。
2. 按住 `Shift`，左键选择 A 点。
3. 继续按住 `Shift`，左键选择 B 点。
4. 程序吸附到最近的真实点云点，并立即显示三维距离、水平距离、高差、坐标差、坡度和倾角。

### 第五步：保存结果

- 点击“保存工程”保存点云路径、测量、相机和分析状态。
- 点击“导出与报告”输出截图、CSV、JSON 或 PDF。
- 源点云或录制文件不会被覆盖；裁剪、清理和变换结果需要显式另存。

## 环境自检与一键安装

![环境自检与一键安装](docs/images/environment-setup.png)

点击左下角“环境安装”会自动检查六组状态：系统编译依赖、当前程序构建、ROS Bag 深度解析环境、MAP BIN 解码器、桌面启动入口，以及 ROS2 Humble。核心依赖必须就绪；Bag、BIN 和桌面入口可以取消勾选。ROS2 不影响离线点云查看，设备驱动工作空间仍在“实时采集”中单独选择和检查。

点击“一键安装所选缺失项”后，程序按依赖顺序执行：

1. 只在系统包确实缺失时申请 APT 权限。
2. 完成或更新程序构建。
3. 按勾选结果补齐 Bag 读取器、BIN 解码器和桌面入口。
4. 安装完成后自动重新检测，以实际状态为准，不把命令退出当作最终成功。

需要 sudo 时会出现密码输入框；字段使用密码遮蔽。密码只发送到 `sudo` 的标准输入，不保存、不写日志，也不放入命令行参数。取消、空密码、认证失败、缺少 sudo 或网络失败都会停止当前安装并显示原因，可以修复后重新检测。若本机仍处于 sudo 的短时认证缓存期，系统不再需要密码，程序会直接使用缓存授权。

自动 APT 安装仅限 README 中列出的固定 Ubuntu 软件包。程序不会自动改动 ROS2、设备驱动工作空间或驱动 YAML；这类设备环境需要按硬件文档安装，并在“实时采集”页选择对应的 `install/setup.bash`。

## 多格式点云加载与查看

### 支持格式

| 输入 | 支持内容 | 颜色与注意事项 |
| --- | --- | --- |
| PCD | ASCII、binary、binary_compressed；XYZ、RGB/RGBA、intensity | 原样保留 RGB/RGBA；无颜色时高度着色 |
| PLY | 常见 ASCII/二进制顶点点云 | 保留可读取的顶点颜色；不把网格面当作测量对象 |
| MAPV0001 `.bin` | Odin1 设备保存的累计地图，已验证 v5 | 官方转换器输出 XYZ，因此通常没有相机颜色 |
| OdinViewer `.olx` | 15 B XYZRGB 和 16 B XYZRGBA 点记录；多帧时间戳 | 保留逐点颜色，并索引同目录位姿和相机数据 |

所有格式都要求有效的 X/Y/Z 坐标。NaN/Inf 会计入“无效点”，但不会进入显示、尺寸、测量和分析计算。

`.bin` 扩展名本身不足以确认文件类型。程序会先检查 `MAPV0001` 魔数；如果选择的是 `OdinPose.bin`、`OdinImage.bin` 等 OLX 配套文件，会提示改为打开同目录中的 `.olx` 主文件。MAP BIN 首次打开前需要运行：

```bash
./scripts/setup_odin_map_tools.sh
```

### 加载方式

- 点击“打开点云”。
- 把支持的文件拖入主窗口。
- 使用“最近文件”。
- 执行 `./run.sh /path/to/cloud.pcd` 或传入其他支持格式。

程序会保留 RGB/RGBA 颜色。没有颜色字段时自动切换为高度渐变，也可以随时选择 RGB、按高度、纯色；OLX 还可按帧着色。

查看选项包括点大小、背景色、坐标轴、地面网格、稳健尺寸框、完整云上下文、文字标签、透视/正交相机、显示点上限和一键适应窗口。默认最多显示 750,000 点；显示降采样只影响渲染，不影响总点数、统计、稳健尺寸、局部分析和最近真实点吸附。

### 地图 BIN 与彩色累计 PCD 的区别

同一次作业保存出的 MAP BIN 和从 `/odin1/cloud_slam` 累计出的彩色 PCD，不一定具有相同点数或边界：前者是设备内部地图格式并经官方工具转成 XYZ，后者是 ROS2 多帧点云的外部累计结果。它们的滤波、抽样、可见帧和颜色来源不同，不能只凭文件名判断内容应完全一致。

本机样本 `map_20260902_103830.bin` 的实际读取结果为 972,514 个 XYZ 点，推荐尺寸约 19.208 × 12.640 × 3.895 m；彩色累计 PCD 则为 1,514,634 点，推荐尺寸约 19.346 × 11.344 × 3.953 m。两组数值均由文件计算，不是程序内置常量。

## Odin1 设备采集与 OLX 回放

### 从已连接的 Odin1 录制

![设备采集与 OLX 录制](docs/images/device-capture.png)

设备采集依赖 ROS2 和已编译的 Odin ROS 驱动工作空间；当前启动脚本按 Ubuntu 快速入门使用 ROS2 Humble（`/opt/ros/humble`）。现有点云的查看、OLX 回放和测量不需要连接设备。

1. 连接 Odin1，在左侧切换到“实时采集”。
2. 选择包含 `install/setup.bash` 的 ROS2 工作空间，例如 `/home/user/odin1_mapping_ws`。
3. 点击“刷新状态”，确认 USB 为 `DEVICE READY`，并检查 ROS2 话题状态。
4. 驱动未运行时点击“启动设备驱动”；已经由终端启动时可直接录制。
5. 选择“SLAM 彩色点云”，并保持默认的“累计建图（逐帧叠加）”；DTOF 原始点云默认使用“当前帧”，避免设备移动时误叠加。
6. 点击“开始扫描并录制”；右侧从空地图开始，新扫到的表面持续加入，已经出现的物体不会被下一帧替换。画面可旋转、缩放，并显示地图点数、当前帧点数、体素和刷新率。
7. 点击“停止并完成”，程序关闭文件并自动回到主窗口播放和测量。

默认话题是 `/odin1/cloud_slam`、`/odin1/odometry` 和 `/odin1/image/compressed`。录制器不会改写驱动 YAML：SLAM 的 `rgb/rgba` 原样写为 XYZRGBA；DTOF 的 intensity 映射为灰度；没有颜色字段时写入中性颜色。相机话题不存在时仍可生成有效 OLX，只是没有相机预览。

累计画面按约 2 cm 起步的空间体素合并重复采样：同一小格再次被扫到时更新其点和颜色，新区域则增加地图点数。接近 60,000 个显示点时会自动增大预览体素，以保持交互流畅；每一帧的完整点云仍直接写入 OLX。预览每 0.2 秒原子刷新，停止时强制发布最后一帧，旋转、缩放和空间去重都不会减少录制文件中的点数。预览临时文件随工作台退出自动清理。

如果只想观察雷达当前一次扫描，可把“实时画面”切换为“当前帧（不叠加）”。每次开始新的录制都会清空上一份预览地图并从第一帧重新生长。

录制目录包含 `MT*.olx`、`OdinPose.bin`、`OdinImage.bin` 和兼容的配套目录。当前工具写入 16 B/点的 XYZRGBA；读取器也兼容已观察到的 15 B/点 XYZRGB 文件。

### OLX 时间轴

![OLX 时间轴和相机同步预览](docs/images/olx-playback.png)

打开 `.olx` 后会出现专用控制轨：

- 播放、暂停、拖动时间轴，并以 0.25×、0.5×、1×、2× 或 4×播放。
- 在“单帧”和“累计”之间切换。
- 累计模式可显示全部历史帧，或只保留指定数量的滑动窗口。
- 同步选择最接近当前点云时间戳的 `OdinImage.bin` 或 `image/*.jpg/png` 画面。
- 显示当前帧号、总帧数、相对时间、累计点数、位姿数和相机帧数。
- 使用 RGB、高程、纯色或帧序号配色；继续使用测量、裁剪、统计和工程保存功能。

为避免大 OLX 占满显存，时间轴显示仍受“显示点上限”控制，但整体统计使用完整会话。选择滑动窗口只改变当前画面，不会修改 OLX。

OLX 不是公开标准；不同固件或软件版本若改变二进制布局，程序会拒绝不一致的数据并报告偏移，而不会猜测后继续读取。

加载完成后，程序会自动计算以下信息：

| 分组 | 数据 |
| --- | --- |
| 文件 | 文件名、路径、大小、编码、字段 |

## 鼠标测量

![八类测量标注演示](docs/images/measurement-demo.png)

> 标注演示同时显示点、线、折线、角度、面积、正交分解、点到平面和圆。实际使用时通常一次只选择一种模式。

### 基本操作

1. 在三维视图上方选择测量模式。
2. 按住 `Shift` 并用左键选点。
3. 点会通过完整点云 KD-tree 吸附到最近的真实点。
4. 达到所需点数后自动生成记录；折线和面积使用“完成”或 `Ctrl+Enter` 结束。

### 测量模式

| 模式 | 选点 | 输出结果 |
| --- | --- | --- |
| 单点坐标 | 1 点 | X、Y、Z |
| 两点测距 | A、B | 三维距离、水平距离、高差、ΔX/Y/Z、坡度、倾角、方位角 |
| 连续折线 | 至少 2 点 | 每段长度、三维累计长度、水平累计长度 |
| 三点角度 | A、顶点 B、C | ∠ABC 和两边长度 |
| 多边形面积 | 至少 3 点 | 拟合平面面积、水平投影面积、周长、拟合 RMS |
| 正交分解 | A、B | 直线距离和 ΔX/ΔY/ΔZ 阶梯线 |
| 点到平面 | P，再选平面 A/B/C | 绝对/有向垂距、投影点和法向 |
| 圆与直径 | 圆周 3 点 | 圆心、半径、直径、周长和圆线 |

两点三维直线距离采用：

```text
sqrt((Bx - Ax)^2 + (By - Ay)^2 + (Bz - Az)^2)
```

单位可在米、厘米和毫米之间切换。界面显示随单位变化，工程和导出的基础坐标始终以米保存。

### 测量记录管理

每次完成测量后会自动编号，并进入记录表。可以：

- 修改名称、分组、备注、颜色、显隐状态和节点坐标。
- 按关键词、类型或分组筛选。
- 一键显示/隐藏整个分组。
- 复制、删除、清空、撤销和重做；历史最多保留 100 步。
- 导出 CSV/JSON，或从 JSON 导入已有测量。
- 关闭画面文字标签，减少记录较多时的遮挡。

导入时会校验类型和几何；未知类型、非法点和退化测量会被跳过，重复 ID 会自动重新编号。

## 选区、裁剪与局部分析

### 选区与裁剪

“区域与分析”支持：

- 鼠标选择两个角点，建立 XY 矩形区域。
- 输入 X/Y/Z 最小值和最大值，建立精确三维框。
- 按高程范围保留或排除点。
- 使用已保存的“多边形面积”记录作为套索边界。
- 对三维框、范围或套索执行反选。
- 显示局部点数、比例、范围、中心、主方向尺寸、密度、间距和高程统计。
- 保留完整点云作为半透明上下文，或只查看当前区域。

裁剪只改变程序内的工作点云。点击“恢复完整点云”可随时返回；只有主动导出时才会生成新的 PCD。

### 局部分析

| 工具 | 主要输出 | 典型用途 |
| --- | --- | --- |
| 区域质量与平面 | 点数、密度、间距、法向、坡度、方位、RMS、最大残差 | 地面或墙面平整度检查 |
| 高程直方图 | 高程分箱、点数图表、CSV/PNG | 观察高度层分布 |
| 高程剖面 | 沿折线的 min/mean/median/max 高程和 CSV | 路线、坡面、管线剖面 |
| 格网挖填体积 | 填方、挖方、净体积、覆盖面积、空格网比例 | 相对基准面的体积估算 |
| 统计离群点 | 邻域异常点检测、预览、应用和 PCD 导出 | 清理散点和飞点 |
| RANSAC 主平面 | 平面方程、内点率、残差、内点 PCD | 提取地面、墙面或台面 |

剖面需要先保存一条折线；格网体积和套索需要先保存一条面积记录。分析摘要会写入当前工程和 PDF 报告。

## 双点云配准与差异

点击“加载第二点云并对比”，把当前点云作为基准云，再选择需要检查的第二份 PCD、PLY、MAP BIN 或 OLX。

### 使用流程

1. 两份点云坐标已经一致时，关闭 ICP，直接计算差异。
2. 存在小幅位置或朝向偏差时，启用质心预对齐和 ICP。
3. 根据点间距设置体素大小、最大迭代次数、最大对应距离和差异阈值。
4. 检查收敛状态、适配度和 4×4 变换矩阵。
5. 查看蓝—青—黄—红差异热力图，并调整第二点云透明度或显隐。
6. 导出对齐后的 PCD、逐点距离 CSV 或摘要 JSON。

结果包括均值、RMSE、中位数、P95、最大距离和超阈值比例。当前实现计算“第二点云 → 基准点云”的单向最近邻距离。

ICP 只做刚体配准，不会修复尺度错误；两份点云重叠不足、初始偏差过大或单位不一致时，结果会失败或失真。

## 坐标工具

坐标工具分为两种行为：

- **显示原点偏移**：只改变界面读数和坐标轴显示，不改变点间距离、面积或导出点云。
- **应用点云变换**：对当前工作点云和全部测量同时执行平移、绕 Z 旋转和统一缩放。

应用变换前可以预览，应用后可以撤销最近一次变换，并可导出变换后的 PCD 和 4×4 矩阵 JSON。为避免混用坐标状态，正式应用变换时会清除当前裁剪、分析和双云对比状态。

源点云或 OLX 永远不会被原地覆盖。

## 工程、恢复与导出

### 工程文件

`.pcdmeasure` 工程会保存：

- 基准点云/OLX 的绝对路径和相对路径。
- OLX 当前帧、单帧/累计模式、滑动窗口、播放倍率和相机预览状态。
- 相机视角、投影模式和显示设置。
- 测量记录、分组和文字样式。
- 当前选区、局部分析、显示原点和累计变换。

派生区域随工程保存时，会生成同名的 `.pcdmeasure.region.pcd` 配套文件；移动工程时需要一起移动。

### 自动恢复

存在实际工作内容时，程序每 60 秒写入自动恢复状态。正常保存或正常退出会清除恢复文件；异常中断后，下次启动会询问是否恢复。

### 导出内容

| 格式 | 内容 |
| --- | --- |
| PNG | 当前三维视图或分析图表 |
| PCD | 当前区域、清理结果、主平面、变换结果或对齐后点云 |
| CSV | 测量记录、剖面、直方图、逐点差异 |
| JSON | 测量、变换矩阵、双云对比摘要、ROS bag 诊断 |
| HTML | 自包含 ROS bag 诊断报告 |

PCD、工程和各类报告使用临时文件与原子提交；写入失败时，不会用不完整文件替换已有目标。

## ROS Bag 回放与离线诊断

![ROS Bag 回放与离线诊断界面](docs/images/rosbag-diagnostics.png)

> 图中使用自动生成的 ROS2 SQLite 测试 bag。诊断界面、表格、状态卡和报告流程均由 GUI 自动测试驱动。

在左侧切换到“Bag 诊断”，或者把支持的 bag 文件/目录拖入主窗口；程序会直接切到内嵌 Bag 工作台。

### 支持范围

| 输入 | 离线诊断 | 回放要求 |
| --- | --- | --- |
| ROS1 `.bag` | 通过 `rosbags` 读取时间、连接信息和内嵌消息定义 | 安装 ROS1，并能执行 `rosbag play` |
| ROS2 bag 目录 / `.db3` | 基础 SQLite 索引；消息类型可用时解析字段 | 安装 ROS2，并能执行 `ros2 bag play` |
| ROS2 `.db3.zstd` | 通过 `rosbags` 解压并诊断 | ROS2 及对应压缩/storage 插件 |
| ROS2 bag 目录 / `.mcap` | 支持独立文件、多分片和内嵌类型定义 | ROS2 及 MCAP storage 插件 |

### 诊断流程

1. 选择 `.bag`、`.db3`、`.mcap`，或选择包含 `metadata.yaml` 的 ROS2 bag 目录。
2. 使用自定义消息时，选择录包工作空间的 `install/setup.bash`。程序也会从 bag 所在目录向上自动查找。
3. 按设备规格调整长间隙、抖动、最低控制频率、TF 跳变和每话题载荷抽样数。
4. 点击“自动诊断”，等待进度达到 100%。
5. 在“诊断总览”“话题时序 / QoS”“TF / 传感器”和“运行日志”中查看证据与修复建议。
6. 导出 JSON 或自包含 HTML 报告；需要复现时设置倍率、循环和 `/clock` 后开始回放。

### 自动检查内容

- **录制概况**：格式、文件大小、时长、消息总数、话题类型、多分片和 metadata 一致性。
- **话题时序**：平均/中位频率、P95/P99 周期、稳健抖动、最大间隙、疑似缺失、重复和回退时间戳。
- **消息时间**：`header.stamp` 有效率、回退；仅在同一时间基准下计算它与 bag 存储时间的 P95/最大偏差。
- **TF**：树断裂、多父节点、环、静态外参变化、无效变换、跳变、速度尖峰、长断档、净位移和累计路径。
- **QoS**：录制 QoS 元数据、混合 reliability/durability，以及 `/tf_static` 的回放风险。
- **传感器**：IMU、LaserScan、PointCloud2、Livox CustomMsg、Image、Odometry、JointState、GNSS、电池和 `/diagnostics`。
- **故障模式**：NaN/Inf、空帧、载荷结构异常、饱和、冻结、噪声、里程计跳变、无定位、低电量、过温和硬件告警。
- **报告**：健康评分、严重度、置信度、证据、影响、修复优先级、能力覆盖率和结论边界。

离线诊断不会启动 ROS 节点，也不会修改 bag。缺少自定义消息时，对应话题仍会完成存储层时序统计，并明确显示字段解析覆盖率。

### 正确理解报告边界

- 健康评分用于排序排查优先级，不是“bag 能否读取”的合格证，也不等同于机器人任务成功率；应同时查看严重度、证据、置信度和解析覆盖范围。
- “疑似丢包”由时间间隙和中位周期估算。没有发布端序号时，无法区分停发、网络丢包和录包漏写。
- `/plan`、`/waypoints`、`/amcl_pose` 等事件/状态话题不会按恒定周期流推断丢包；`/tf` 的聚合发布抖动也不会替代逐变换链检查。
- bag 含 `/clock` 且 header 使用仿真纪元时，header 与 Unix 存储时间的固定差值不是传输延迟；报告会提示回放启用 `use_sim_time`，但不把纪元差记为严重故障。
- TF 断档只在动态 TF 消息完整解析时判断。使用载荷抽样时仍检查树结构、外参和可见跳变，但会明确跳过不可靠的断档结论。
- 离线 bag 不包含目标订阅者的完整运行时配置，因此 QoS 只能指出元数据缺失或冲突风险，最终兼容性需要在回放环境确认。
- TF 净位移可能是机器人正常运动。异常判断应结合瞬时跳变、断档、速度尖峰和树结构错误。
- 传感器规则是通用诊断基线，应根据设备量程、额定频率和工作场景调整阈值。

## 精度、性能与数据安全

### 精度

- 程序默认把点云坐标解释为米；导入前应确认数据单位。
- 鼠标点通过完整点云吸附，不会吸附到显示降采样产生的近似点。
- 稳健尺寸会降低少量离群点的影响，但不会自动判断场景真实边界。
- 面积依赖拟合平面，体积依赖边界、基准高程和格网尺寸，结果应结合 RMS 与空格网比例判断。
- ICP 结果依赖重叠率、初始位置、点密度和参数；应同时查看适配度和差异分布。
- 最终现场误差还受传感器标定、SLAM 漂移、运动畸变、点云分辨率和人工选点影响。

### 性能

- 默认显示上限为 750,000 点，可按显卡和内存情况降低。
- 点数、包围盒、测量吸附和分析始终使用完整有效点云。
- 耗时分析在后台执行并显示忙碌状态；运行期间不要重复加载同一任务。
- 真实 1,514,634 点基准云在验证电脑上完成 GUI 加载与完整自动回归；不同电脑耗时会不同。

### 数据安全与隐私

- 点云和 bag 分析均在本机完成，程序不会主动上传用户数据。
- 源点云、OLX、第二点云和原始 bag 以只读方式使用。
- 裁剪、清理、配准和坐标变换只修改内存中的工作副本。
- 只有用户主动保存时才创建工程或导出文件。
- 工程、PCD 和报告采用原子写入，尽量避免失败时留下半文件。

## 常见问题

### 双击桌面图标没有反应

先右键图标选择“允许启动”。仍无反应时，在项目目录运行 `./run.sh`，终端会显示缺失依赖或启动错误。

### 编译时找不到 Qt、PCL 或 VTK

程序还能启动时，打开左下角“环境安装”，点击“一键安装所选缺失项”。首次安装或程序无法启动时，重新执行 `./install_desktop.sh`；也可以手动执行“系统要求”中的 `apt install` 命令。如果并行编译被系统终止，使用：

```bash
PCD_MEASURE_BUILD_JOBS=1 ./build.sh
```

### 点云没有彩色画面

检查右侧字段是否包含 `rgb` 或 `rgba`。只有 XYZ 的 PCD、PLY 或 MAP BIN 无法恢复原始颜色，程序会自动按高度着色；全黑 RGB 也会显示较低的“非黑彩色点比例”。

### MAP BIN 无法打开

先执行 `./scripts/setup_odin_map_tools.sh`。程序只接受带 `MAPV0001` 魔数的设备地图；`OdinPose.bin` 和 `OdinImage.bin` 不是独立点云，应打开同目录中的 `.olx`。

### OLX 能打开但没有相机画面

点云颜色和相机帧是两路数据。确认会话目录包含非空 `OdinImage.bin` 或 `image/*.jpg/png`；如果录制时 `/odin1/image/compressed` 不存在，OLX 点云仍然有效，但不会显示相机预览。不要仅为获取图像盲目修改设备驱动参数，应先用 `ros2 topic list` 和设备固件说明确认支持情况。

### 设备采集显示 USB 正常但 ROS2 未就绪

确认所选工作空间存在 `install/setup.bash`。可先点击“启动设备驱动”，等待 `/odin1/cloud_slam` 或 `/odin1/cloud_raw` 出现后再录制；如果驱动已在其他终端运行，只需刷新状态，不要重复启动。

### 开始录制后实时画面仍为空

先确认状态显示 `ROS2 · CLOUD READY`，扫描模式选择“SLAM 彩色点云”，实时画面选择“累计建图（逐帧叠加）”，并检查对应话题正在持续发布。画面在收到第一帧后从空地图开始增长；它显示点云而不是相机视频。若写盘点数持续增加但地图没有更新，可查看右下日志中的预览写入错误，完整 OLX 录制不会因预览不可用而停止。

### 大点云旋转或缩放卡顿

降低“显示点上限”和点大小，关闭文字标签、网格或完整云上下文。这样不会降低统计和测量精度。

### 测量点选不中想要的位置

先放大目标区域并切换到合适的标准视角，再按 `Shift` 点击。吸附目标来自当前工作区域；若已裁剪，请确认目标点仍在区域内。

### 工程打开后找不到点云

把 PCD 和 `.pcdmeasure` 恢复到保存时的相对位置。如果工程使用派生区域，还要带上 `.pcdmeasure.region.pcd` 配套文件。

### ICP 失败或结果明显错误

确认两云单位一致、有足够重叠且初始偏差不大。可启用质心预对齐，适当增大最大对应距离或减小体素大小；尺度不一致必须先用坐标工具修正。

### Bag 只能完成基础时序诊断

执行 `./scripts/setup_rosbag_tools.sh`，并在窗口中选择录包时对应工作空间的 `install/setup.bash`。自定义消息可用后，报告中的“字段解析覆盖率”会提高。

### ROS1、MCAP 或压缩 Bag 无法读取

确认 `.rosbag-venv` 已成功安装，网络可用，并安装了 `python3-venv`。然后重新运行 `./scripts/setup_rosbag_tools.sh`。

### Bag 可以诊断但无法回放

诊断读取器和 ROS 回放环境是两套依赖。请确认 `rosbag` 或 `ros2 bag` 可以在终端运行，并安装对应的 SQLite/MCAP/压缩 storage 插件和自定义消息包。

### 点击“打开完整报告”没有反应

程序会优先调用桌面设置中的默认网页浏览器，并在 HTML 文件关联错误时直接回退到 Edge、Chrome、Firefox 或 Chromium。更新程序后请先关闭旧窗口再重新双击桌面图标。仍无法启动浏览器时，可点击“导出 HTML 报告”后从文件管理器打开，或指定浏览器再启动：

```bash
PCD_MEASURE_HTML_OPENER=/usr/bin/firefox ./run.sh
```

### 回放后节点收不到话题

使用 `ros2 topic info -v` 核对订阅端的 reliability 和 durability，重点检查 `/tf_static`；同时确认回放工作空间、`ROS_DOMAIN_ID`、仿真时间和自定义消息类型一致。
